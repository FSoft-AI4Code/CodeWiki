## 安装 CodeWiki

要开始使用 CodeWiki，您需要通过 pip 安装该工具。CodeWiki 支持 Python 3.12 及以上版本，因此请确保您的 Python 环境满足要求。

### 安装步骤

1. 打开终端或命令行工具。
2. 运行以下命令从 GitHub 安装 CodeWiki：

```bash
pip install git+https://github.com/FSoft-AI4Code/CodeWiki.git
```

3. 安装完成后，验证安装是否成功：

```bash
codewiki --version
```

如果安装成功，您将看到类似 `CodeWiki CLI v1.0.0` 的输出。

**注意**：如果您遇到权限问题，可以尝试使用 `pip install --user` 命令，或者在虚拟环境中安装。

**中文**
- **安装命令**：`pip install git+https://github.com/FSoft-AI4Code/CodeWiki.git`
- **验证命令**：`codewiki --version`

## 配置 LLM API 密钥和模型

安装完成后，您需要配置 LLM（大语言模型）API 密钥和模型设置。CodeWiki 支持多种 LLM 提供商，如 Anthropic、OpenAI 等。

### 配置步骤

1. 获取您的 LLM API 密钥（例如，从 Anthropic 或 OpenAI 获取）。
2. 运行以下命令配置 CodeWiki：

```bash
codewiki config set \
  --api-key YOUR_API_KEY \
  --base-url https://api.anthropic.com \
  --main-model claude-sonnet-4 \
  --cluster-model claude-sonnet-4 \
  --fallback-model glm-4p5
```

### 配置选项说明

- `--api-key`：LLM API 密钥，将安全地存储在系统密钥链中（macOS Keychain、Windows Credential Manager 或 Linux Secret Service）。
- `--base-url`：LLM API 的基础 URL，例如 `https://api.anthropic.com`。
- `--main-model`：用于文档生成的主要模型，推荐使用高质量模型如 `claude-sonnet-4`。
- `--cluster-model`：用于模块聚类的模型，建议使用顶级模型以确保文档质量。
- `--fallback-model`：备用模型，当主模型不可用时使用。

**中文**
- **API 密钥**：`--api-key YOUR_API_KEY`
- **基础 URL**：`--base-url https://api.anthropic.com`
- **主模型**：`--main-model claude-sonnet-4`
- **聚类模型**：`--cluster-model claude-sonnet-4`
- **备用模型**：`--fallback-model glm-4p5`

## 生成文档

配置完成后，您可以开始为代码库生成文档。CodeWiki 会分析代码库并生成全面的文档。

### 生成步骤

1. 导航到您要生成文档的项目目录：

```bash
cd /path/to/your/project
```

2. 运行以下命令生成文档：

```bash
codewiki generate
```

3. 如果您希望生成适用于 GitHub Pages 的 HTML 查看器，并创建一个新分支，可以使用以下命令：

```bash
codewiki generate --github-pages --create-branch
```

### 生成选项说明

- `--output`：指定输出目录，默认为 `./docs`。
- `--create-branch`：创建一个新的 Git 分支用于文档更改。
- `--github-pages`：生成 `index.html` 以支持 GitHub Pages 部署。
- `--no-cache`：强制重新生成，忽略缓存。
- `--verbose`：显示详细进度和调试信息。
- `--language`：指定生成文档的语言（如 `english` 或 `chinese`）。

**中文**
- **输出目录**：`--output ./documentation`
- **创建分支**：`--create-branch`
- **GitHub Pages**：`--github-pages`
- **忽略缓存**：`--no-cache`
- **详细模式**：`--verbose`
- **文档语言**：`--language chinese`

## 查看生成的文档

文档生成完成后，您可以在 `./docs/` 目录中查看生成的文件。

### 主要文件

- `overview.md`：项目概述，包含架构指南和模块分析。
- `module1.md`、`module2.md` 等：各个模块的详细文档。
- `module_tree.json`：模块的层次结构。
- `metadata.json`：生成元数据。
- `index.html`：交互式查看器（如果启用了 `--github-pages`）。

### 查看方式

1. 打开 `overview.md` 文件，了解项目的整体架构。
2. 如果生成了 `index.html`，可以在浏览器中打开它，以交互方式浏览文档。

**中文**
- **项目概述**：`overview.md`
- **模块文档**：`module1.md`
- **模块树**：`module_tree.json`
- **元数据**：`metadata.json`
- **HTML 查看器**：`index.html`

## 常见问题与故障排除

在使用 CodeWiki 时，您可能会遇到一些常见问题。以下是一些解决方案。

### Python 版本要求

CodeWiki 需要 Python 3.12 或更高版本。如果您的 Python 版本过低，请升级到最新版本。

### Node.js 依赖

CodeWiki 使用 Mermaid 图表来生成架构图，因此需要 Node.js 来验证这些图表。请确保已安装 Node.js 14.0.0 或更高版本。

### Git 仓库要求

如果您使用 `--create-branch` 选项，项目必须是一个 Git 仓库。如果不是，请先初始化 Git 仓库：

```bash
git init
```

### API 密钥问题

如果 API 密钥无效或未设置，CodeWiki 将无法连接到 LLM 服务。请确保正确配置了 `--api-key` 和 `--base-url`。

### 权限问题

如果遇到权限错误，请确保输出目录可写，并且您有权限创建文件和目录。

**中文**
- **Python 版本**：`Python 3.12+`
- **Node.js 版本**：`Node.js 14.0.0+`
- **Git 仓库**：`git init`
- **API 密钥**：`--api-key YOUR_API_KEY`
- **权限问题**：`chmod u+w /path/to/output`
