## 简介
`format_user_prompt`函数是CodeWiki系统中用于构建LLM可解析输入的核心机制。该函数接收模块名称、核心组件ID列表、组件字典和模块树结构等参数，将其格式化为结构化的用户提示。此提示包含模块的层次化树状表示、核心组件的分组信息以及完整的文件内容，支持多语言输出，为AI代理生成高质量文档提供必要的上下文信息。

## 核心组件
`format_user_prompt`函数是用户提示构建的核心，它接收多个关键参数并生成结构化的LLM输入。该函数通过递归遍历模块树生成层次化表示，并在当前模块处标注"(current module)"。函数还负责将核心组件按文件路径分组，并使用EXTENSION_TO_LANGUAGE映射确定代码块的语言标识。

## 模块树结构处理
`format_user_prompt`函数通过递归方式处理模块树结构，生成层次化的树状表示。函数内部定义了`_format_module_tree`辅助函数，该函数遍历模块树的每个节点，根据缩进级别构建层次结构。当遇到当前模块时，会在模块名称后添加"(current module)"标记，以突出显示当前处理的模块。

```mermaid
flowchart TD
Start([开始格式化模块树]) --> IterateNodes["遍历模块树节点"]
IterateNodes --> CheckCurrentModule{"是否为当前模块?"}
CheckCurrentModule --> |是| AppendCurrent["添加 '(current module)' 标记"]
CheckCurrentModule --> |否| AppendNormal["正常添加模块名称"]
AppendCurrent --> AddCoreComponents["添加核心组件列表"]
AppendNormal --> AddCoreComponents
AddCoreComponents --> CheckChildren{"是否有子模块?"}
CheckChildren --> |是| ProcessChildren["递归处理子模块"]
CheckChildren --> |否| Continue["继续下一个节点"]
ProcessChildren --> IterateNodes
Continue --> CheckMoreNodes{"还有更多节点?"}
CheckMoreNodes --> |是| IterateNodes
CheckMoreNodes --> |否| End([完成模块树格式化])
```

## 核心组件分组机制
函数通过`grouped_components`字典将核心组件按文件路径进行分组。该机制遍历核心组件ID列表，从组件字典中获取每个组件的相对路径，并将相同路径的组件ID归入同一组。这种分组方式确保了来自同一文件的组件被集中处理，便于后续的代码内容整合。

```mermaid
flowchart TD
Start([开始分组核心组件]) --> InitializeDict["初始化 grouped_components 字典"]
InitializeDict --> IterateComponents["遍历核心组件ID列表"]
IterateComponents --> GetComponent{"组件ID在组件字典中?"}
GetComponent --> |否| SkipComponent["跳过该组件"]
GetComponent --> |是| GetRelativePath["获取组件的相对路径"]
GetRelativePath --> CheckPathInDict{"路径已在字典中?"}
CheckPathInDict --> |否| CreateNewGroup["创建新组"]
CheckPathInDict --> |是| UseExistingGroup["使用现有组"]
CreateNewGroup --> AddToGroup["将组件ID添加到对应路径组"]
UseExistingGroup --> AddToGroup
AddToGroup --> Continue["继续下一个组件"]
Continue --> CheckMoreComponents{"还有更多组件?"}
CheckMoreComponents --> |是| IterateComponents
CheckMoreComponents --> |否| End([完成分组])
```

## 代码内容整合与语言识别
在分组完成后，函数构建包含文件路径、核心组件列表和完整文件内容的结构化输入。对于每个文件路径，函数使用EXTENSION_TO_LANGUAGE映射来确定代码块的语言标识。该映射支持多种编程语言，包括Python、JavaScript、TypeScript、Java、C++、C#和PHP等。函数通过文件扩展名查找对应的语言标识，并将其用于代码块的语法高亮。

```mermaid
flowchart TD
Start([开始整合代码内容]) --> IteratePaths["遍历分组后的路径"]
IteratePaths --> AddFilePath["添加文件路径标题"]
AddFilePath --> AddCoreComponentsHeader["添加核心组件标题"]
AddCoreComponentsHeader --> ListComponents["列出该路径的所有组件ID"]
ListComponents --> DetermineLanguage["确定文件扩展名对应的语言"]
DetermineLanguage --> AddCodeBlockHeader["添加代码块标题和语言标识"]
AddCodeBlockHeader --> ReadFileContent["读取文件完整内容"]
ReadFileContent --> HandleError{"读取失败?"}
HandleError --> |是| AddErrorComment["添加错误注释"]
HandleError --> |否| AddFileContent["添加文件内容"]
AddErrorComment --> CloseCodeBlock["关闭代码块"]
AddFileContent --> CloseCodeBlock
CloseCodeBlock --> Continue["继续下一个路径"]
Continue --> CheckMorePaths{"还有更多路径?"}
CheckMorePaths --> |是| IteratePaths
CheckMorePaths --> |否| End([完成代码内容整合])
```

## 提示模板结构
`format_user_prompt`函数最终使用USER_PROMPT模板构建完整的用户提示。该模板包含模块名称、格式化的模块树和核心组件代码三个主要部分。所有内容都通过`{language}`占位符支持多语言输出，确保生成的文档符合指定的语言要求。

```mermaid
flowchart TD
USER_PROMPT[用户提示模板] --> ModuleName["模块名称占位符 {module_name}"]
USER_PROMPT --> LanguageInstruction["语言指令部分"]
USER_PROMPT --> ModuleTree["模块树部分 {module_tree}"]
USER_PROMPT --> CoreComponentCodes["核心组件代码部分 {formatted_core_component_codes}"]
USER_PROMPT --> LanguagePlaceholder["语言占位符 {language}"]
LanguageInstruction --> InstructionContent["包含语言指令的详细说明"]
ModuleTree --> TreeContent["包含层次化模块树结构"]
CoreComponentCodes --> FileSection["文件路径标题 # File: path"]
CoreComponentCodes --> ComponentsSection["核心组件列表 ## Core Components in this file:"]
CoreComponentCodes --> ContentSection["文件内容 ## File Content:
```language```"]
```
